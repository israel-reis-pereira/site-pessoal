## O que é

O **DEVmoda** foi desenvolvido como parte da construção do meu portfólio durante a graduação em Sistemas de Informação.

O projeto começou com uma proposta de interface para uma loja virtual e evoluiu como um laboratório para estudar desenvolvimento front-end, responsividade, JavaScript, consumo de APIs e integração experimental com inteligência artificial.

Mais do que representar uma loja pronta para produção, o projeto registra uma etapa importante da minha evolução no desenvolvimento de interfaces e na integração entre diferentes recursos do front-end.
